Thirteen line icons from the concept page: 24px viewBox, 1.7px stroke, round caps and joins, no fills. Each file is drawn in `green` (#173e35); in pages use the inline `<symbol>` sprite instead so the icon takes `currentColor` (sage-icon in fields, sage-deep in trust circles, on-sand on sand buttons). `up` is the diagonal arrow for outbound links and "Begär offert"; `arrow` is the straight arrow on primary buttons; `golf` is the flag on the green.
